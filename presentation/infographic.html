⚖️ Maker ≠ Checker
The builder never certifies its own work. Every role runs in an isolated context — the one who builds never grades their own "done."
🎯 Project Identity
project.md anchors everything. Out-of-scope work is rejected at intake grooming, not at review time. Identity is not a sprint goal.
🔧 Fix the harness, not the code
Every escaped defect becomes a new guard. Skills encode blessed conventions — concurrency, indexing, datetime, API — applied at P2 and P4.
💾 .harness/ — durable memory
On-disk project spine: decisions, logs & evidence. The AI interaction log is captured continuously — not reconstructed at the end.
