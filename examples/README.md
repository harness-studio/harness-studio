# Examples — illustrations, NOT part of the framework

Harness Studio is the **generic generator**: it runs engagements and produces applications. The files in here are **Layer-2 illustrations** — example engagements you could run *through* the framework. They carry no blessed status and are not part of the framework; swap in your own.

- [`example-engagement.md`](example-engagement.md) — a generic, invented engagement brief (a link-shortener with click analytics) + a worked "requirements → Definition-of-Done" extraction. Use it to see the flow end-to-end. For real work, paste **your own** brief into the kickoff (`../04-KICKOFF.md`).

> The framework itself is domain-agnostic. Concrete cases (an inventory app, a trading app, anything) are *outputs* of harness-studio, not part of it.
